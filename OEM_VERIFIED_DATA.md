# OEM / Chevrolet Volt data policy

This project intentionally separates verified data from unverified OEM commands.

Verified public examples included as catalog references: U007A (HV energy management communication bus off) and P0AA6 (hybrid battery voltage system isolation lost) for 2012 Chevrolet Volt. Sources are public service-manual references.

The app does not enable ECU write, security access, flash programming, immobilizer/key or high-voltage safety routines without an explicit verified vehicle/module profile, preconditions, and controlled hardware validation.
