## 4. Reading this report

* Counts are over the definitions in the shipped catalog. A definition says where a value is supposed to be; only a positive reply from a real car shows that it is. None of this research talked to a car.
* A vehicle missing from a table has no definition in the catalog. It does not mean the vehicle has no such data or no reset.
* 'Non-debug' means the community has not flagged the command 'dbg' (OBDb's schema describes the flag as: whether to debug the signal responses). It is not a statement that anyone verified the definition on a car.
* The Service page's normal refresh sends the non-debug definitions of the exact model and the brand-wide identifiers of its make; other research definitions only on request. The Mileage page requests the exact model's definitions whether or not they are flagged debug.
* The OBDb files used here are the default signal set of each vehicle; year-range override files are not included.
* The model-year of a vehicle is not part of a catalog row, so every figure is per model.
* Names of makes follow the catalog (for example 'Land' for Land Rover, 'Alfa' for Alfa Romeo, 'Rolls' for Rolls-Royce).
